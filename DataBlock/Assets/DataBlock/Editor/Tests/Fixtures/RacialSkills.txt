```
《魔法代謝》
〈種族特性〉
【習得条件】種族選択時に自動習得
【パッシブ効果】
MP最大値が×1.2倍される。
MPが0以下になった時、《戦闘不能》状態になる。
――――――――――――――――
魔法生物の身体は常に魔法が巡り生命維持に欠かせない機能を果たしている。
故に他の種族よりも魔法の適正が高いが、
その代わりにマナの全てを失うと命を落としてしまう。
```

```
《エレメンタルエコー》
〈種族スキル〉
【習得条件】種族選択時に任意選択
【パッシブ効果】自身が〈精霊魔法〉を発動するたびに属性に応じた状態を1スタック得る。
火属性：《火精の昂り》, 水属性：《水精のさざめき》, 風属性：《風精の囁き》
電属性：《雷精の轟き》, 冷属性：《氷精の嬉笑》, 土属性：《土精の踊躍》
※複数属性の場合はそれぞれ1種類ずつ。

効果〈顕現〉：自身の〈精霊魔法〉による消費ACTはその属性の[属性に応じたスタック]×3につき1減少する。
さらにスタックが3つ溜まるごとにACTが1回復する。
※複数属性の場合はどちらか片方の種類を参照。
――――――――――――――――
火は心を熱く、水は記憶を揺らし、風は未来を唄う。
雷は真理を叫び、氷は夢を笑い、土は歩みに寄り添う。

エルフその精霊の名を呼べば呼ぶほどに、
その声は世界に響き、更なる力を引き出すだろう。
```

```
《エレメンタルウィスパー》

【習得条件】種族選択時に任意選択

――――――――――――――――
精霊の声を聴き精霊と歌う力がエルフの耳には備わっている。
```
