# 獣人のスキル・特性 その2

`獣人が実装すべき特性とスキルその2.txt` の45件について、Inspectorの構文統一・シリアライズセット・テキスト再構築・JSON出力に対応する文章変換とモデルを追加した。戦闘実行はJSONの利用側で行う。初回追加時には、依頼に従いテスト・ビルド・Inspector操作を実施していない。以下はデータ表現と解釈の記録。

## 対応した処理

- エリア進行ロールの任意軽減、アイテム使用コスト、初回ターンの資源増加と宣言制限。
- 毎ターンのスタック獲得、上限付き威力倍率、スタックに比例した回復・消費・属性威力。
- 水中での能力値・判定補正、水棲の移動制限、特性の無効化。
- 絡み手・拘束の移動禁止、付与者または対象の接近解除に連動する状態解除、付与者のターン開始時の攻撃。
- 煙幕の選択制限、防御点補正、フェーズ別の被ダメージ倍率、対象種族別の判定補正。
- 自属性・弱点・自属性に応じた命中時の追加効果、自属性がない場合の通常威力のみの攻撃。
- カウンターFumbleによる暴走、任意の地面効果免疫、スキル固有のCritical範囲。
- 滞空・着陸・ロールプレイの選択式、飛行の維持コストと目標値補正、次の攻撃1回だけの威力補正。
- 回復禁止、ランダム対象選択、命中時の拘束・沈黙、罠の自動発動と処理後の除去。
- 味方が付与した状態の種類数による威力、ダメージ処理後のHP閾値による戦闘不能。
- 戦闘中1度の追加カウンター、次の宣言の任意対象追加、ディスティニースパイクの段階上昇。

## 既存の表現として扱った箇所

- 通常の直接攻撃・武器威力・消費・判定・接近・状態付与・解除・Critical/Fumble・スパイクは従来の型を使用。
- 唄の「スタックを付与される」は `GainStack`。「スタックの付与数が2」は直前の唯一の付与先を特定して `SetStackAmount`。
- 毎ターンの回復・消費は `RestoreResource / ConsumeResource` とターン開始トリガー。自身のターン指定を `Self`、指定のない毎ターンを既存の `Any` として区別。
- 《夕凪》の段階的な倍率は `MultiplyPowerByStacks`。増加・減少の両方に使えるよう、出力を「変化する」に統一。
- 防御点や最大HPは `ModifyStat`。判定の倍率や目標値、被ダメージ倍率も既存の補正型を使用。
- 《森渡り》は既存の進行ロール軽減の通常値0・条件付き値2。《鳥人の空旅》は条件なしの軽減1。
- 《忍糸》は既存の罠設置・召喚定義・処理後除去。状態説明の後の除去文を罠の宣言効果に戻す。

## 入力補正・解釈

- スパイク見出しの閉じ括弧、威力変更の「威力は」、カテゴリー付き状態見出しの「効果」を共通の構文補正として補う。状態名は固定しない。
- 全角の「１ターン」、「対象をを」、改行された一続きの効果文、状態解除条件の誤った「●」、2個のバッククォートによる開始フェンスを補正。
- 《ドラグブレス》の「重複可能」は `AllowDuplicates` として明示し、指定なしや重複不可と区別する。
- 《絡み付き》の攻撃を付与者のターン・現在のステータスに基づいて扱う場合は、原文に付与者を明記する必要がある。「自身のターン」を付与者のターンへ自動変更する処理は行わない。状態内の「自身」は状態保持者を指す。《海鳴》は明記されたとおり威力算出時の付与者を参照する。
- 《雁字搦め》は味方（自身を含む）が付与した**状態の種類数**を数える。同種の付与件数やスタック数ではない。
- 自属性の最大値が同点の場合の選び方、暴走の追加の発動時刻、原文にない状態解除時期は決めていない。
- スパイク上昇は既存の上位段階を利用する規則として保存し、第4段階を新設しない。
- サードスパイクだけが存在する場合の「セカンドスパイク：無し」の出力は維持。
- フレーバーは変更しない。

## モデル変更

- `ConditionModels.cs`：62 `AreaWithoutCategory`、63 `SelectCharactersWithState`、64 `AutomaticEnemyAction`。通常の対象選択に `AllowDuplicates` を追加。
- `EffectModels.cs`：`TriggerTiming.AttackHit = 26`。`EffectContentType` の70〜89に、エリア制限・特性抑制・自属性・命中時分岐・ランダム化・禁止・追加宣言などを追加。
- `OverrideContentType` の51〜64に、上限付きスタック倍率・エリア補正・付与者の属性威力・種族別判定・自属性ボーナス・次回補正・Critical範囲・アイテムコスト・フェーズ倍率を追加。
- 各enumのパラメーター順と適用範囲は `EffectModels.cs` の各項目のコメントに記載。既存enumの番号は変更していない。
- `SkillModels.cs` と `StateModels.cs` のフィールド追加は不要。JSONの `Skill / Summons / States` 構造を維持。

入力の整形は `SkillInputTextCodec`、共通文型は `SemanticRuleTextCodec`、効果の読み取り・再構築は `SkillEffectReaders / SkillContentTextCodec`、状態の効果・補正は `StateEffectTextCodec / StateModifierTextCodec`、整合性と参照先の検証は `SkillEffectValidation / SkillDataValidation` が担当する。
