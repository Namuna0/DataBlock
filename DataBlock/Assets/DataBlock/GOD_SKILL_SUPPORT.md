# 神族のスキル・特性

`神族のスキルと特性.txt` の12件を対象に、Inspectorの構文統一 → シリアライズセット → テキスト再構築 → JSON出力で使用する文章変換とデータ表現を追加した。JSONの `Skill / Summons / States` 構造は維持する。戦闘実行・式の評価は従来どおりJSONの利用側で行う。

依頼に従い、テスト・ビルド・Inspector操作は実施していない。

## 対応内容

| スキル・特性 | 対応 |
|---|---|
| 天使の制約 | 装備可能なスキル数の上限式。習得数の制限とは別に保存 |
| 天使の飛行 | 滞空・着陸・下瞰の選択式、屋内以外の宣言条件、移動無効、攻撃目標値補正、自身のターン開始時のACT・MP消費 |
| 天撃 | 主旋律・重唱の選択式、不足ACTの後払い、聖律による消費軽減と威力補正、攻撃後の全スタック除去、期限付きスタック付与 |
| 聖光の弓 | 対象の最大HPの20%のダメージと、防御点・効果・状態による威力／被ダメージ増減の禁止 |
| 祈り | 自身を除く対象への祝福、全行為判定の達成値補正 |
| 古代の支配者 | プレイヤーがその場にいるロスト状態のキャラクターの使用、使用時の状態効果無視、状態解除禁止 |
| 古代神の儀式 | 儀式魔法・古代儀式魔法の行為判定達成値補正 |
| シェミナの印 | 指定特性を習得した獣人の選択、SANを0に設定、発狂・ロストの両方を付与 |
| 古代神の叡智 | 既存の知力Bによる行為判定補正 |
| 制約の降臨 | 通常時のパッシブ無し、スパイク段階で利用可能な戦闘中1度の任意付与、経験値・決意の消費、全能力値Bの倍率 |
| 神業の如き | 自身の全行為判定の達成値補正 |
| 奇跡にも似た | 通常失敗した発動ロールを成功に変更するカウンター。戦闘中1度の制限 |

## 既存表現の再利用と入力補正

- 《天使の飛行》は獣人の飛行と同じ構成として扱った。維持消費がSPではなくMPである点は、既存の `ConsumeResource` のリソース名で表す。状態・子スキル・エリア条件・目標値・ロールプレイは既存型を再利用。
- 《祈り》《神業の如き》《古代神の儀式》の達成値補正は既存の `AddActionResult` とトリガーの組み合わせ。状態の「自身」は状態保持者を指す。
- 「儀式魔法及び古代儀式魔法」は、どちらのカテゴリーでも補正されるORトリガーとした。同じ行為が両方に一致しても、同じ補正を二重適用する指定ではない。
- 《天撃》の「自身は16d100…の威力で攻撃する」は主語を示す表記と判断し、宣言条件で選択した1体への `SkillAttack(Target, 式)` に統一した。この省略形は、ちょうど1体を選ぶ宣言条件がある場合に限って受け付ける。自分自身への攻撃には変換しない。
- 《天撃》の後払い、ロスト状態の説明など、一続きの効果文に挿入された改行を結合する。
- 《制約の降臨》の開始コードフェンスが欠けている箇所は、当該見出しが既存のコードブロック外に現れた場合に開始フェンスを補う。通常のフェンス付き入力やフェンスなしの単独入力は維持する。
- 《制約の降臨》の「パッシブ効果：無し」は空の通常効果として保存し、スパイクによる任意付与がある場合は再構築にも「無し」を出す。
- サードスパイクのみの場合に空のセカンドスパイクを表示する従来仕様は維持。
- フレーバーは補正の対象外。

## 実装上の解釈・適用範囲

- 「消費ACT及びMPは0以下にはならない」は、文言どおり**最低消費1**。聖律3スタックなら、主旋律の基礎ACT16・MP18に各18の軽減を適用した後、両方を1に制限する。
- 後払いは、軽減と最低消費を適用した後のこのスキルのACT不足分。現在支払える分を支払い、残りを**自身の次のターン開始時**に支払う。MPまで後払いにする規則は追加しない。
- 聖律による消費・威力は、攻撃後にスタックを除去する前の値を参照する。発動の宣言時点で先に除去する表現にはしていない。
- 重唱の1ターンは、今回付与するスタックの期限。既存の別のスタックや同名状態全体の期限を上書きする指定ではない。
- 《聖光の弓》は威力・ダメージ量の増加と軽減を禁止する。必中、回避不能、効果の無効化自体への免疫など、原文にない規則は追加しない。
- 《古代の支配者》はロスト状態の解除・蘇生ではない。プレイヤーの在席条件と、ロスト状態が解除できないことを保持する。
- 《制約の降臨》の経験値・決意は**それぞれ30**を消費する。スパイク段階の任意付与として `Overrides` に保存し、自動的な常時状態付与にはしない。各段階の「戦闘中1度」を保持し、段階間で共有する使用回数などは追加していない。どのスパイク段階を適用するかは既存の段階選択規則に従う。
- 能力値Bの倍率は、基礎能力値そのものの倍率とは区別する。
- 《奇跡にも似た》は、反応元の通常失敗した発動ロールを成功にする。再ロール、Criticalへの変更、このカウンター自身の自動成功ではない。

## 変換処理

`GodRuleTextCodec.cs` は意味を持つ型と文型の対応、`GodTextCodec.cs` は入力補正・条件・既存型の補正表現、`GodValidation.cs` は整合性検査を扱う。

対応する消費のない後払い・消費軽減、攻撃のないスタック威力補正や攻撃後除去、通常失敗条件のない成功変更、状態定義のないスパイク付与などは再構築時に拒否する。これは実装した検査であり、今回は動作テストを実施していない。
