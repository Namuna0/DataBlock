# 非生物のスキル・特性

`非生物の実装範囲.txt` の22件に対する文章変換・データ表現。Inspectorの構文統一 → シリアライズセット → テキスト再構築 → JSON出力で使用する。JSONの外形は従来の `Skill / Summons / States` を維持する。戦闘処理そのものは従来どおりJSONの利用側で実行する。

依頼に従い、テスト・ビルド・Inspector操作は実施していない。

## 表記の統一と解釈

- 《不変の身体》の主語省略、重症ロール省略、免疫、経験値増加は既存の `PreventRollAtResource / CategoryImmunity / AddQuestReward` に対応させた。
- 《元素適応》の自属性は獣人その2の `DefineOwnAttribute / OwnAttributeBonus` を再利用。最大値が同点の場合の優先属性は原文にないため、決めていない。
- 防御点、直接攻撃、Critical/Fumble、スパイク、通常回復、継続ダメージ、器用B・敏捷Bの判定倍率は既存型を再利用した。
- 「状態キャラクター」は「状態のキャラクター」に統一。「まで」は `UpTo` として保存し、ちょうど指定数を選ぶ `Exact` と区別する。
- 《月影の呪縛》は付与先が《回復阻害》、説明見出しが「回復無効効果」になっている。**付与先と《銀耐性》の参照に合わせ、このブロック内だけ「回復阻害効果」に統一する。** 《半魔の呪縛》の《回復無効》はそのまま残す。
- 《クリムゾンブレード》の「深紅の剣〈顕現〉」には「効果」を補う。**直後の流血付与文は直前の斬撃武器による付与の重複説明として1件にまとめる。** 種族・状態・ターン数が直前の付与と完全に一致する場合に限る。威力補正も同じ斬撃武器の武器攻撃に適用する。
- 上記2点は原文の不整合に対する実装上の解釈であり、原文が明示している別効果として増やしていない。
- 「銀および神聖術を受けた時」は、いずれかを受けた時というOR条件として保存する。両カテゴリーを同時に必要としない。
- 「既に流血」は**攻撃前**の対象状態。今回の命中で付与した流血によって、その攻撃自体が強化されることはない。
- 《銀耐性》《日光耐性》は発生源が《月影の呪縛》の不利益だけを抑制する。他の特性・攻撃による同名状態やダメージを無効にする効果ではない。
- 「SANが存在せず」はSAN=0とは別の規則として保存する。発狂免疫も独立して保存する。
- 「永続的な炎上」は環境条件とターン上限なしの付与を保持する。原文にない環境変更時の自動解除条件は追加しない。
- 《自爆》は敵味方全ての戦闘参加者を対象とし、自身の除外は追加しない。戦闘不能**になった時**の宣言は、戦闘不能状態である間という条件とは別に保存する。
- 吸血の2種類の回復は、そのスキルの攻撃による実ダメージを参照する。一般のダメージや他の攻撃には連動しない。
- 《屍布の返呪》の相手は自身を選択した行動者。敵だけという制限、スタック上限・消費・解除時期は追加しない。付与と回復はそれぞれ任意。
- フレーバー本文は補正の対象外。

## Runtime/Model の変更

既存enumの番号は変更していない。パラメーターは表の順に文字列で保存する。

### ConditionModels.cs

- `OwnStateApplied = 65`：状態名。自身がその状態になった時の宣言。
- `SelectCharactersWithState = 63`：既存の `[状態名, 人数]` に加え `[状態名, 人数, Exact|UpTo]` を扱う。省略時はExact。

### 既存型への追加表現

- `SkillAttack` の対象に `AllBattleCharacters` を追加。
- `RestoreFromDamage [Self, リソース, 倍率]` を `DamageDealt + ActionSource(Self) + ActionOrigin(ThisSkill)` と組み合わせて吸血を保存。
- `RestoreResource` を `TurnStart + TurnOwner(Self)` と組み合わせて自身のターン開始時回復を保存。
- `MultiplyResourceDamage [Self, リソース, 倍率, Automatic]` と `DamageDealt + ActionSource(Self)` で与えるリソースダメージを補正。
- `AddActionResult [-(減少式)]` と `ActionResult + ActionSource(Self)` で全行為判定を減少。
- 命中時の単純な状態付与は `ApplyState` と `AttackHit` を再利用。

## 変換処理

`NonlivingRuleTextCodec.cs` は専用の意味を持つ型と文章の対応、`NonlivingTextCodec.cs` は入力補正・既存型の追加表現・状態文・整合性検査を扱う。文型を共有するため、獣人その2の内部文型クラスを `SkillTextRule` に改名し、両方の文型を参照するようにした。

対応する攻撃のない命中効果・吸血・流血威力補正、文型と異なる効果種別、パラメーター数の不一致などは再構築時に拒否する。これは実装した検査であり、今回は動作テストを実施していない。
